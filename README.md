# 生存游戏剧情

## 项目介绍

这是一个基于Vue 3和TypeScript开发的生存游戏剧情Demo，旨在展示一个完整的剧情系统架构。项目包含了剧情播放、分支选择、属性面板、历史回溯等核心功能，并且设计了一个灵活的剧本数据结构，方便后续扩展和维护。

## 项目功能

- 剧情播放：根据剧本数据，动态渲染游戏场景和对话。
- 分支选择：玩家可以在每个节点选择不同的分支，影响游戏的走向。
- 属性面板：显示玩家当前的状态，包括生命值、属性值等。
- 历史回溯：玩家可以回溯到之前的节点，重新选择路径。

## 项目描述

项目采用了模块化设计，核心功能被封装在独立的组件和模块中。剧情数据以结构化的方式存储，支持多章节和多分支的复杂剧情。通过使用Vue 3的组合式API和TypeScript的类型系统，确保了代码的可读性和可维护性。

## 项目架构

项目采用了经典的三层架构设计，分为表现层（Presentation Layer）、业务逻辑层（Business Logic Layer）和数据层（Data Layer）。每一层都负责不同的职责，确保代码的清晰和可维护性。

## 项目组件

项目包含了以下核心组件，用于构建游戏界面和实现功能：

- VideoPlayer.vue：视频播放器，支持跳过、倍速播放。
- ChoiceOverlay.vue：分支选择遮罩层，用于显示分支选项。
- StatusPanel.vue：属性面板，显示角色好感度、情报值等属性。
- HistoryTimeline.vue：历史时间轴，记录游戏历史事件。
- TypewriterText.vue：打字机效果文本，用于显示剧情文本。

| 模块     | 文件数 | 核心功能                                                 |
| :------- | :----- | :------------------------------------------------------- |
| 类型定义 | 2      | 完整的TypeScript类型系统                                 |
| 核心引擎 | 3      | 剧情推进、状态管理、存档系统                             |
| 状态管理 | 2      | Pinia Store（游戏状态、进度存档）                        |
| 通用组件 | 5      | 视频播放、分支选择、状态面板、历史回溯、打字机效果       |
| 页面视图 | 7      | 主菜单、章节选择、游戏主界面、设置、画廊、结局、制作人员 |
| 数据配置 | 4      | 角色配置、成就系统、章节剧本（2章示例）                  |
| 工程配置 | 3      | Vite、TypeScript、HTML入口                               |
